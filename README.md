# WebApp ресторана

WebApp предназначен для отдельного ресторана, созданного через материнского бота. Для ресторана создаётся собственный бот, а пользователь, который его настраивает, является администратором. Приложение относится только к этому ресторану: оно не объединяет его с другими ресторанами, созданными таким же способом.

## Возможности

- просмотр меню, категорий и карточек товаров;
- корзина и оформление заказа;
- просмотр истории заказов и административный раздел;
- PHP API для работы с меню, заказами, оплатой и данными ресторана.

## Структура проекта

- `src/` — клиентское приложение на React и TypeScript;
- `api/` — PHP API для приложения ресторана;
- `api_bot/` — PHP API для создания и управления ботом ресторана;
- `public/` — статические ресурсы frontend.

Frontend собирается с помощью Vite. PHP API использует PostgreSQL через PDO; в `api_bot/` также указаны Composer-зависимости.

## Запуск frontend

Требуется Node.js и npm.

```bash
npm install
npm run dev
```

Для production-сборки и проверки кода:

```bash
npm run build
npm run lint
```

Предварительный просмотр production-сборки:

```bash
npm run preview
```

## Backend

Для работы API требуется PHP с PDO и драйвером PostgreSQL. Чтобы установить зависимости `api_bot/`, выполните:

```bash
cd api_bot
composer install
```

Разместите каталоги `api/` и `api_bot/` на PHP-сервере и настройте соединение с PostgreSQL в файлах `db.php` соответствующих каталогов. PHP API должен быть доступен frontend по адресам, к которым обращается приложение.
